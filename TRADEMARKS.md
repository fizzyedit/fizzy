# Trademarks

The code is MIT (`LICENSE`); the name is not. "Fizzy" and the Fizzy logo are trademarks of
Colton Franklin. This policy exists so that a person who downloads something called Fizzy gets
Fizzy, and it is meant to stay out of the way of everyone building on it.

## Fine without asking

- Saying what your work is for: "a plugin for Fizzy", "built with Fizzy", "Fizzy theme pack".
- Redistributing an unmodified Fizzy build under its own name and logo.
- Packaging Fizzy for an operating system or package manager, with only the changes needed to
  build and install it there.
- Writing, teaching, streaming and talking about Fizzy, logo included.
- Naming a plugin `fizzy-<thing>` or `<thing>-for-fizzy`.

## Ask first

- Calling a modified build "Fizzy", or shipping it with the Fizzy logo or icon.
- A product, company or domain name that contains "Fizzy" or could be mistaken for it.
- Using the logo in a way that suggests the project endorses or sponsors you.

A fork is welcome; give it a name and icon of its own and say it is based on Fizzy.

## Asking

Open an issue on [`fizzyedit/fizzy`](https://github.com/fizzyedit/fizzy/issues). Reasonable
requests get a yes.
