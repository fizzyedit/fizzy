# Text


Built-in [Fizzy](../../../readme.md) plugin. Text is the universal fallback editor: it opens any file no other plugin
claims, as an editable, monospace document tab in the Workbench workspace.

---

| Features | Description |
|---|---|
| rainbow brackets | matches brackets with a color palette |
| LSP client | Interface for providing LSP support for languages |

See also [markdown](../markdown/README.md) which is a plugin that extends this one.
