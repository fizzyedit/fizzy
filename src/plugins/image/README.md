# Image
 
Built-in [Fizzy](../../../readme.md) plugin. This plugin is responsible for intercepting documents that are registered images (.PNG, .JPEG, .JPG) and rendering them as an image viewer rather than allowing the Text plugin to render the plain text.

| Features | Description |
|---|---|
| pan | smoothly pan and move the image using trackpad or middle mouse, click and drag also works with momentum
| zoom | smoothly zoom in and out of images using the scroll wheen on mouse or `cmd/ctrl + scroll` on a trackpad
